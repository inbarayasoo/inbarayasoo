## 💡 My Projects

### 🧊 Embedded & Network Projects

- [**SensorLink**](https://github.com/inbarayasoo/SensorLink):
  An end-to-end telemetry system in C++. FreeRTOS firmware on an emulated ARM Cortex-M node streams checksummed packets over TCP to an epoll-based Linux server, which fans out live data, applies backpressure to slow devices, and raises latched alerts. Benchmarked with up to 1000 simulated devices.
- [**Smart Dog Feeder**](https://github.com/inbarayasoo/smart_dog_feeder):
  An IoT smart pet feeder. An ESP32 controls a stepper motor, a load cell and a distance sensor, and a Flutter app with a Firebase backend manages feeding schedules and live status. Keeps feeding on the last saved schedule when Wi-Fi drops.

### 💪 Software Projects

- [**FitPlan**](https://github.com/inbarayasoo/FitPlan):
  A workout-tracking REST API in C++20 with a coach side and a trainee side. Coaches build plans and assign them; trainees log sessions and see progress. One process, one SQLite file, with a lightweight web frontend and Docker deployment.
